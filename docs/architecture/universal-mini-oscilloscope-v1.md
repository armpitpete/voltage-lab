# Universal Mini-Oscilloscope v1.0

The Universal Mini-Oscilloscope gives every Voltage Lab module one small, consistent output-shape preview. It makes the declared port, signal representation and declared range visible before a learner starts patching.

## What it shows

- one declared output from each module
- a deterministic illustrative waveform appropriate to that output's teaching purpose
- the declared range and whether it is conceptual modular voltage or browser-normalised audio
- a concise teaching explanation of the shape

## Teaching truth

These traces are **illustrative declared-output previews**. They are deliberately labelled as such. They do not claim to be live module runtime samples, Web Audio samples or cable signals. The future connection engine will supply live signal evidence to the same visual language.

## Boundary

This release does not create sockets, cables, connection state, signal routing, audio routing, patch storage or missions. Existing module controls, models, primary visualisations and audio demonstrations remain unchanged.
