# Accessibility and teaching contract

- Controls use visible labels and touch-sized targets.
- Core actions work with mouse, touch and keyboard focus.
- Colour is reinforced with names and readouts.
- Exact values appear as text rather than relying on graph interpretation.
- Learn mode provides one bounded experiment at a time.
- Explore mode removes lesson framing without hiding controls.
- Audio is opt-in and always has a panic/stop action.
- Motion can be slowed, paused and advanced one step at a time.
